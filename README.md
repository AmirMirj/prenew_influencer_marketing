# Reach

Find small gaming creators other tools miss — ranked, with a pitch ready.

Built for the Prenew challenge: refurbished gaming PCs, Europe, micro and mid-tier creators.

## Demo (60 seconds)

1. Open the app. Germany results load on their own.
2. Point at a **Hidden gem** (small, engaged, on-niche).
3. Click **Copy pitch** — it is already in German. Toggle **Show English** if needed.
4. Click **Find hidden gems in Finland** to show local-language search (`pelikone`, `käytetty`).
5. **Export for outreach** if you want the CSV story.

## Run locally

```bash
npm install
npm test
npm run dev
```

Optional `.env.local`: `YOUTUBE_API_KEY`, `OPENAI_API_KEY`. The demo works without them.
